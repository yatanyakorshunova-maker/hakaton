# Марсоход: начальное решение

Этот ZIP можно сразу загрузить в кабинет хакатона. Сервер соберёт образ по
`Dockerfile`, запустит `train.py` и возьмёт сохранённую модель из
`/output/policy.onnx`.

Для первой доработки откройте `model.py`: там описана сеть, которая получает
160 показаний и выбирает одну из 31 команды. Затем откройте `train.py`:
там находятся параметры обучения. Можно заменить сеть, способ обучения и
тренировочные участки, сохранив формат входов и выходов модели.

Основные файлы:

| Файл | Для чего нужен |
|---|---|
| `train.py` | Запускает обучение и сохраняет модель |
| `model.py` | Пример сети с памятью |
| `python/mars_rover_env/configs/env.yaml` | Параметры тренировочного мира |
| `cpp/include/mars/custom_biomes.inc.hpp` | Место для новых тренировочных участков |
| `Dockerfile` | Устанавливает библиотеки и собирает C++ среду |

Во время заезда выбранная команда действует восемь шагов физики. Заезд длится
не больше 300 секунд. При поломке он заканчивается, и следующий заезд начинается
в новом мире. На проверке считаются 48 заездов; балл — медиана наибольших
расстояний. Подробности формата есть на странице **«Инструкция»** сайта.

Если хотите проверить среду на своём компьютере, установите Python 3.10+,
компилятор C++20, `setuptools`, `wheel` и `pybind11`, затем выполните:

```bash
python -m pip install setuptools wheel pybind11
python -m pip install --no-build-isolation --force-reinstall .
python -m unittest discover -s tests -v
```

После короткого обучения проверьте сохранённую модель командой
`python check_policy.py путь/к/policy.onnx`. В начальном образе она проверяет
формат и размеры; если установлен `onnxruntime`, дополнительно пробует исполнить
модель. Окончательный заезд на закрытых трассах проводит сервер.

Чтобы собрать ZIP после изменений, выполните `python package_submission.py`.
Появится `submission.zip`: отправьте его через кабинет. Готовый Docker-образ
публиковать не требуется.
